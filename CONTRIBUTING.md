# Working with this lab

1. Fork or clone the repository.
2. Recreate the Cisco topology and adapt interface names to your Packet Tracer router model.
3. Implement the pfSense VM policy separately, or use GNS3/EVE-NG for a unified virtual topology.
4. Run the validation checklist and record only observed outcomes.
5. Replace placeholders, remove sensitive material, add screenshots, and commit your own `.pkt` file if suitable for public sharing.

Pull requests should describe topology changes, updated addressing, security impact, and tests performed.
