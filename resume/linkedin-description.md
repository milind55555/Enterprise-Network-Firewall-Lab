# LinkedIn project description

**Enterprise Network & Firewall Lab | Cisco Packet Tracer, VLAN, OSPF, ACL, pfSense, OpenVPN**

Designed a two-site office network for HQ and a branch location. Segmented staff, guest, server, and management traffic using VLANs; implemented router-on-a-stick inter-VLAN routing and OSPF area 0 over a routed WAN link; and centralized DHCP/DNS services with DHCP relay. Added extended ACLs to prevent guest-to-internal access, and documented pfSense perimeter firewall policies, outbound NAT, and restricted OpenVPN remote access. Included device configurations, an IP addressing plan, architecture diagrams, and a validation checklist.

**Note:** The Cisco topology is recreated in Packet Tracer; pfSense firewall/VPN is a companion VM lab because Packet Tracer does not emulate pfSense.
